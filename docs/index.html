QoL Enhancements for Peanuts

Turns the Switch download of Arcusaren's QoL Enhancements 1.1.0 into a mod zip for Peanuts Native (ACNH 3.0.3). It all runs in your browser; nothing is uploaded.

  1. Download Main download (Modded Switch) from GameBanana (qol-switch-v1_1_0-acnh-v3_0_3.zip).
  2. Download qol-peanuts-patch.json from the latest release.
Pick both files.

Then in Peanuts: ACNH's settings, Install mod… > Zip file, pick qol-enhancements-peanuts.zip. Source and details.
