QoL Enhancements for Peanuts

Turns the Switch download of Arcusaren's QoL Enhancements 1.1.0 into a mod zip for Peanuts Native. It all runs in your browser; nothing is uploaded.

  1. 1

    Get the mod

    Download Main download (Modded Switch) from GameBanana (qol-switch-v1_1_0-acnh-v3_0_3.zip).

  2. 2

    Get the patch

    Download qol-peanuts-patch.json from the latest release.

  3. 3

    Make the zip

Status

Pick both files.

Then, in Peanuts

Open ACNH's settings, then Install mod… > Zip file, and pick qol-enhancements-peanuts.zip. Peanuts rebuilds the game with the mod, which takes about 5 minutes.
